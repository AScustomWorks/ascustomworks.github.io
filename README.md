# AS Custom Works

Website for the AS Custom Works plugins for [VCV Rack 2](https://vcvrack.com/), published with GitHub Pages.

- [AS Seqs & Tools](https://ascustomworks.github.io/seqs-n-tools/): [VCV Library](https://library.vcvrack.com/AS-Seqs-n-Tools)
- [AS Drums & Filters](https://ascustomworks.github.io/drums-n-filters/): [VCV Library](https://library.vcvrack.com/AS-Drums-n-Filters)
- Free and open source [AS modules](https://github.com/AScustomWorks/AS)

Found a bug in a module? Please [open an issue](https://github.com/AScustomWorks/ascustomworks.github.io/issues) and include the plugin, module, Rack version and operating system.
